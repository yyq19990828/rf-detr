# RF-DETR 训练参数说明

本文档说明 `tools/train.py` 当前支持的训练参数，内容已按仓库现有 `model.train()` / `TrainConfig` 对齐。

## 快速开始

### 基础用法

```bash
# 使用默认参数训练 Medium 模型
python tools/train.py --dataset-dir datasets/my_dataset

# 训练 YOLO 数据集
python tools/train.py \
    --model small \
    --dataset-file yolo \
    --dataset-dir datasets/my_yolo_dataset

# 多目录联合训练
python tools/train.py \
    --model medium \
    --dataset-dir datasets/set_a \
    --dataset-dir datasets/set_b
```

### 常用命令

```bash
# 快速验证
python tools/train.py \
    --model nano \
    --dataset-dir datasets/my_dataset \
    --epochs 10 \
    --batch-size 8 \
    --no-run-eda \
    --no-tensorboard

# 从检查点恢复训练
python tools/train.py \
    --model medium \
    --dataset-dir datasets/my_dataset \
    --resume output/checkpoint.pth

# 启用更多日志能力
python tools/train.py \
    --model large \
    --dataset-dir datasets/my_dataset \
    --wandb \
    --project rf-detr-training \
    --run exp-01
```

## 使用说明

- `--dataset-dir` 可以重复传入，也支持逗号分隔。多目录训练时，各目录类别顺序必须一致。
- 当前脚本支持 `coco`、`roboflow`、`yolo` 三种数据集格式，默认是 `roboflow`。
- 很多布尔参数同时支持 `--foo` 和 `--no-foo` 两种写法。
- 当前默认值里，`--use-ema` 为关闭，`--run-test` 为关闭，`--progress-bar` 为关闭，`--tensorboard` 为开启，`--run-eda` 为开启。
- `--group-detr`、`--num-select`、`--num-classes`、`--ia-bce-loss`、`--pretrain-weights` 属于模型构造参数；脚本不会再把它们传给 `TrainConfig`。这是为了避开上游已弃用的 `TrainConfig.group_detr` / `TrainConfig.num_select` / `TrainConfig.ia_bce_loss` 字段，以及 `TrainConfig` 不支持的 `num_classes` 字段。
- `--pretrain-weights` 用于从指定权重初始化一个新训练；`--resume` 用于恢复一次未完成的训练，两者语义不同。

## 数据集格式

### COCO / Roboflow

```text
dataset/
├── train/
│   └── _annotations.coco.json
├── valid/
│   └── _annotations.coco.json
└── test/
    └── _annotations.coco.json
```

### YOLO

```text
dataset/
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
├── test/
│   ├── images/
│   └── labels/
└── data.yaml
```

如果目录里没有 `data.yaml`，但存在 `classes.yaml` / `classes.yml`，脚本会尝试自动补一个 `data.yaml`。

## 参数详细说明

### 1. 模型与输入

| 参数             | 类型   | 默认值     | 说明                                                      |
| ---------------- | ------ | ---------- | --------------------------------------------------------- |
| `--model`, `-m`  | str    | `medium`   | 模型变体，可选 `nano`、`small`、`medium`、`large`、`base` |
| `--dataset-dir`  | str    | 必填       | 数据集目录，可重复传入                                    |
| `--dataset-file` | str    | `roboflow` | 数据集格式，可选 `coco`、`roboflow`、`yolo`               |
| `--class-names`  | str... | `None`     | 手动指定类别名，未提供时由数据集自动推断                  |
| `--aug-config`   | JSON   | `None`     | 自定义增强配置，传 JSON 对象字符串                        |
| `--output-dir`   | str    | `output`   | 输出目录                                                  |
| `--resume`       | str    | `None`     | 从指定训练状态检查点恢复训练                              |
| `--pretrain-weights` | str | `None` | 用指定权重初始化模型，开始一轮新训练 |
| `--num-classes`  | int    | `None`     | 手动指定目标类别数；未提供时训练入口会尝试从数据集自动推断 |
| `--group-detr`   | int    | `13`       | 模型架构 Group-DETR 分组数                                |
| `--num-select`   | int    | `300`      | 模型后处理保留的候选框数量                                |
| `--ia-bce-loss` / `--no-ia-bce-loss` | bool | `True` | 模型架构相关 loss 开关 |

`--aug-config` 示例：

```bash
python tools/train.py \
    --dataset-dir datasets/my_dataset \
    --aug-config '{"HorizontalFlip": {"p": 0.5}}'
```

### 2. 优化与训练轮次

| 参数                   | 类型  | 默认值   | 说明                          |
| ---------------------- | ----- | -------- | ----------------------------- |
| `--epochs`             | int   | `100`    | 总训练轮数                    |
| `--batch-size`         | int/`auto` | `4` | 每步批大小；传 `auto` 时自动探测安全 micro-batch |
| `--grad-accum-steps`   | int   | `4`      | 梯度累积步数                  |
| `--device`             | str   | `None`   | 训练设备，如 `cpu`、`cuda`、`cuda:0`、`mps`；默认由框架自动选择 |
| `--lr`                 | float | `1e-4`   | 主学习率                      |
| `--lr-encoder`         | float | `1.5e-4` | 编码器学习率                  |
| `--weight-decay`       | float | `1e-4`   | 权重衰减                      |
| `--lr-drop`            | int   | `100`    | `step` 调度器的衰减轮数       |
| `--warmup-epochs`      | float | `0.0`    | 学习率预热轮数                |
| `--lr-vit-layer-decay` | float | `0.8`    | ViT 分层学习率衰减            |
| `--lr-component-decay` | float | `0.7`    | 组件学习率衰减                |
| `--lr-scheduler`       | str   | `step`   | 调度器，可选 `step`、`cosine` |
| `--lr-min-factor`      | float | `0.0`    | `cosine` 调度器最低学习率比例 |
| `--clip-max-norm`      | float | `0.1`    | 梯度裁剪阈值                  |
| `--drop-path`          | float | `0.0`    | DropPath 概率                 |
| `--seed`               | int   | `None`   | 随机种子，默认不显式固定      |

### 2.1 自动 batch size

| 参数                             | 类型  | 默认值 | 说明                                                   |
| -------------------------------- | ----- | ------ | ------------------------------------------------------ |
| `--auto-batch-target-effective`  | int   | `16`   | `--batch-size auto` 时每设备目标 effective batch size  |
| `--auto-batch-max-targets-per-image` | int | `100` | 自动探测时假设的每张图最大目标数                       |
| `--auto-batch-ema-headroom`      | float | `0.7`  | 启用 EMA 时对探测 batch size 应用的安全余量倍率        |

示例：

```bash
python tools/train.py \
    --model medium \
    --dataset-dir datasets/my_dataset \
    --batch-size auto \
    --auto-batch-target-effective 32
```

### 3. EMA 与早停

| 参数                                                       | 类型  | 默认值  | 说明                    |
| ---------------------------------------------------------- | ----- | ------- | ----------------------- |
| `--use-ema` / `--no-use-ema`                               | bool  | `False` | 是否启用 EMA            |
| `--ema-decay`                                              | float | `0.993` | EMA 衰减率              |
| `--ema-tau`                                                | int   | `100`   | EMA tau                 |
| `--ema-update-interval`                                    | int   | `1`     | EMA 更新间隔            |
| `--early-stopping`                                         | bool  | `False` | 是否启用早停            |
| `--early-stopping-patience`                                | int   | `10`    | 早停耐心值              |
| `--early-stopping-min-delta`                               | float | `0.001` | 最小改进阈值            |
| `--early-stopping-use-ema` / `--no-early-stopping-use-ema` | bool  | `False` | 早停时是否基于 EMA 指标 |

### 4. 数据加载与增强

| 参数                                                                   | 类型 | 默认值  | 说明                                     |
| ---------------------------------------------------------------------- | ---- | ------- | ---------------------------------------- |
| `--num-workers`                                                        | int  | `2`     | DataLoader worker 数                     |
| `--prefetch-factor`                                                    | int  | `None`  | 每个 worker 的预取批次数                 |
| `--pin-memory` / `--no-pin-memory`                                     | bool | `None`  | 显式设置 DataLoader `pin_memory`         |
| `--persistent-workers` / `--no-persistent-workers`                     | bool | `None`  | 显式设置 DataLoader `persistent_workers` |
| `--multi-scale` / `--no-multi-scale`                                   | bool | `True`  | 是否启用多尺度训练                       |
| `--expanded-scales` / `--no-expanded-scales`                           | bool | `True`  | 是否启用扩展尺度采样                     |
| `--square-resize-div-64` / `--no-square-resize-div-64`                 | bool | `True`  | 是否启用 64 对齐的方形缩放               |
| `--do-random-resize-via-padding` / `--no-do-random-resize-via-padding` | bool | `False` | 是否启用基于 padding 的随机缩放          |

说明：

- 分割任务通常要求 `square_resize_div_64=True`。
- `pin_memory` 和 `persistent_workers` 默认交给框架自行决定，只有需要强制覆盖时再显式传参。

### 5. 模型架构与评估

| 参数                                                     | 类型  | 默认值  | 说明                         |
| -------------------------------------------------------- | ----- | ------- | ---------------------------- |
| `--group-detr`                                           | int   | `13`    | 模型架构 Group-DETR 分组数；传给模型构造参数 |
| `--num-select`                                           | int   | `300`   | 模型后处理保留的候选框数量；传给模型构造参数 |
| `--num-classes`                                          | int   | `None`  | 目标类别数；传给模型构造参数 |
| `--cls-loss-coef`                                        | float | `1.0`   | 分类损失权重                 |
| `--ia-bce-loss` / `--no-ia-bce-loss`                     | bool  | `True`  | 是否启用 IA BCE loss；传给模型构造参数 |
| `--eval-max-dets`                                        | int   | `500`   | 每张图最多参与评估的检测框数 |
| `--eval-interval`                                        | int   | `1`     | 每隔多少个 epoch 做一次验证  |
| `--log-per-class-metrics` / `--no-log-per-class-metrics` | bool  | `True`  | 是否记录每类指标             |
| `--save-val-predictions` / `--no-save-val-predictions`   | bool  | `True`  | 是否保存验证预测结果         |
| `--run-test` / `--no-run-test`                           | bool  | `False` | 训练完成后是否跑 test 集     |
| `--run-eda` / `--no-run-eda`                             | bool  | `True`  | 训练前是否生成 EDA 汇总      |

## 训练策略建议

### 快速验证

```bash
python tools/train.py \
    --model nano \
    --dataset-dir datasets/my_dataset \
    --epochs 10 \
    --batch-size 8 \
    --no-run-eda \
    --no-run-test \
    --no-tensorboard
```

### 标准训练

```bash
python tools/train.py \
    --model medium \
    --dataset-dir datasets/my_dataset \
    --epochs 200 \
    --batch-size 4 \
    --grad-accum-steps 4 \
    --lr 1e-4 \
    --early-stopping \
    --early-stopping-patience 15
```

### YOLO 数据集训练

```bash
python tools/train.py \
    --model small \
    --dataset-file yolo \
    --dataset-dir datasets/my_yolo_dataset \
    --epochs 100 \
    --batch-size 8 \
```

```bash

    --nproc_per_node=2 \
    tools/train.py \
    --model medium \
    --dataset-dir datasets/my_dataset \
    --batch-size 2 \
    --strategy ddp \
    --devices 2 \
    --grad-accum-steps 8

./tools/train.sh
```

## 输出文件说明

训练过程中，`output_dir` 下常见文件包括：

```text
output/
├── checkpoint.pth
├── latest.ckpt
├── training_config.json
├── checkpoint0009.pth
├── checkpoint_best_regular.pth
├── checkpoint_best_ema.pth
├── checkpoint_best_total.pth
├── log.txt
├── metrics_plot.png
├── results.json
├── results_mask.json
├── train_eda_summary.json
└── eval/
    └── latest.pth
```

说明：

- `checkpoint.pth` 是最近一次训练状态，适合用于 `--resume`。
- `latest.ckpt` 是 PyTorch Lightning 路径下最近一次训练状态，适合用于 `--resume`。
- `checkpoint_best_total.pth` 是最终最佳权重，已裁剪为更适合推理的形式。
- `training_config.json` 保存本次训练的完整 `train_config`、`model_config`、类别名和类别数，便于复现实验。
- `results.json` 保存验证 / 测试指标摘要。
- `results_mask.json` 只在分割任务下生成。
- `train_eda_summary.json` 在启用 `--run-eda` 时生成。
- `metrics_plot.png` 是训练曲线汇总图。

## 常见问题

### 显存不足

- 降低 `--batch-size`
- 提高 `--grad-accum-steps`
- 降低 `--num-workers`
- 选择更小的模型，如 `nano` 或 `small`

### 训练速度慢

- 增加 `--num-workers`
- 适当提高 `--batch-size`
- 关闭 `--run-eda`
- 在可接受精度损失时关闭 `--multi-scale`

### 过拟合

- 启用 `--early-stopping`
- 增加 `--weight-decay`
- 调低学习率
- 用 `--aug-config` 增强数据扰动

### 想继续上次训练

- 传入 `--resume output/checkpoint.pth`
- 如果是 YOLO 数据集，别忘了同时保留 `--dataset-file yolo`
