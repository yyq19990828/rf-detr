# RF-DETR 训练参数说明

本文档详细说明了 `tools/train.py` 脚本支持的所有训练参数。

## 快速开始

### 基础用法

```bash
# 使用默认参数训练 Medium 模型
python tools/train.py --dataset-dir datasets/my_dataset

# 训练 Nano 模型，自定义轮数和批大小
python tools/train.py --model nano --dataset-dir datasets/my_dataset --epochs 200 --batch-size 8
```

### 常用训练命令

```bash
# 小数据集快速训练
python tools/train.py --model nano --dataset-dir datasets/small_dataset --epochs 50 --batch-size 16 --lr 2e-4

# 大数据集生产训练
python tools/train.py --model medium --dataset-dir datasets/large_dataset --epochs 300 --batch-size 4 --grad-accum-steps 8 --early-stopping --wandb

# 启用所有日志记录的完整训练
python tools/train.py --model large --dataset-dir datasets/full_dataset --epochs 500 --tensorboard --wandb --project "rf-detr-training"
```

## 参数详细说明

### 模型选择

| 参数            | 类型 | 默认值 | 说明                                     |
| --------------- | ---- | ------ | ---------------------------------------- |
| `--model`, `-m` | str  | medium | 选择模型变体: nano, small, medium, large |

**模型特点对比：**

- **nano**: 最轻量，适合快速原型和资源受限环境
- **small**: 平衡速度和精度，适合边缘设备部署
- **medium**: 推荐选择，替代已弃用的 Base 模型
- **large**: 最高精度，适合对准确性要求极高的场景

### 数据集参数

| 参数            | 类型 | 是否必需 | 说明                   |
| --------------- | ---- | -------- | ---------------------- |
| `--dataset-dir` | str  | ✅       | COCO格式数据集目录路径 |

**数据集目录结构要求：**

```
dataset/
├── train/
│   └── _annotations.coco.json
├── valid/
│   └── _annotations.coco.json
└── test/
    └── _annotations.coco.json
```

### 训练基础参数

| 参数                 | 类型 | 默认值 | 说明                                                     |
| -------------------- | ---- | ------ | -------------------------------------------------------- |
| `--epochs`           | int  | 100    | 训练总轮数                                               |
| `--batch-size`       | int  | 4      | 每个批次的样本数                                         |
| `--grad-accum-steps` | int  | 4      | 梯度累积步数，等效批大小 = batch_size × grad_accum_steps |
| `--num-workers`      | int  | 2      | 数据加载器工作进程数                                     |

**批大小选择建议：**

- GPU内存 \<= 8GB: batch-size=2, grad-accum-steps=8
- GPU内存 12-16GB: batch-size=4, grad-accum-steps=4
- GPU内存 >= 24GB: batch-size=8, grad-accum-steps=2

### 学习率参数

| 参数              | 类型  | 默认值 | 说明                               |
| ----------------- | ----- | ------ | ---------------------------------- |
| `--lr`            | float | 1e-4   | 主学习率                           |
| `--lr-encoder`    | float | 1.5e-4 | 编码器学习率（通常略高于主学习率） |
| `--weight-decay`  | float | 1e-4   | 权重衰减率，用于正则化             |
| `--warmup-epochs` | int   | 0      | 学习率预热轮数                     |
| `--lr-drop`       | int   | 100    | 学习率衰减轮数                     |

**学习率调节建议：**

- 小数据集（\<1000图片）：lr=2e-4
- 中等数据集（1000-10000图片）：lr=1e-4（默认）
- 大数据集（>10000图片）：lr=5e-5

### 输出控制

| 参数                    | 类型 | 默认值 | 说明                               |
| ----------------------- | ---- | ------ | ---------------------------------- |
| `--output-dir`          | str  | output | 训练输出目录（模型、日志、检查点） |
| `--checkpoint-interval` | int  | 10     | 检查点保存间隔（轮数）             |

### EMA (指数移动平均)

| 参数          | 类型  | 默认值 | 说明                     |
| ------------- | ----- | ------ | ------------------------ |
| `--use-ema`   | flag  | True   | 启用EMA，提高模型稳定性  |
| `--no-ema`    | flag  | -      | 禁用EMA                  |
| `--ema-decay` | float | 0.993  | EMA衰减率，越接近1越平滑 |

### 早停机制

| 参数                         | 类型  | 默认值 | 说明                                 |
| ---------------------------- | ----- | ------ | ------------------------------------ |
| `--early-stopping`           | flag  | False  | 启用早停，防止过拟合                 |
| `--early-stopping-patience`  | int   | 10     | 早停耐心值（连续多少轮无改进后停止） |
| `--early-stopping-min-delta` | float | 0.001  | 早停最小改进阈值                     |

### 日志记录

| 参数               | 类型 | 默认值 | 说明                     |
| ------------------ | ---- | ------ | ------------------------ |
| `--tensorboard`    | flag | True   | 启用TensorBoard日志记录  |
| `--no-tensorboard` | flag | -      | 禁用TensorBoard          |
| `--wandb`          | flag | False  | 启用Weights & Biases日志 |
| `--project`        | str  | None   | W&B项目名称              |
| `--run`            | str  | None   | W&B运行名称              |

### 数据增强

| 参数               | 类型 | 默认值 | 说明                           |
| ------------------ | ---- | ------ | ------------------------------ |
| `--multi-scale`    | flag | True   | 启用多尺度训练，提高模型鲁棒性 |
| `--no-multi-scale` | flag | -      | 禁用多尺度训练                 |

### 测试控制

| 参数         | 类型 | 默认值 | 说明                   |
| ------------ | ---- | ------ | ---------------------- |
| `--run-test` | flag | True   | 训练完成后自动运行测试 |
| `--no-test`  | flag | -      | 训练完成后跳过测试     |

## 训练策略建议

### 快速验证策略

适用于验证数据集和模型配置：

```bash
python tools/train.py \
    --model nano \
    --dataset-dir datasets/my_dataset \
    --epochs 10 \
    --batch-size 8 \
    --no-test \
    --no-tensorboard
```

### 标准训练策略

适用于大多数训练场景：

```bash
python tools/train.py \
    --model medium \
    --dataset-dir datasets/my_dataset \
    --epochs 200 \
    --batch-size 4 \
    --grad-accum-steps 4 \
    --lr 1e-4 \
    --early-stopping \
    --early-stopping-patience 15 \
    --tensorboard
```

### 高精度训练策略

适用于追求最佳性能：

```bash
python tools/train.py \
    --model large \
    --dataset-dir datasets/my_dataset \
    --epochs 500 \
    --batch-size 2 \
    --grad-accum-steps 8 \
    --lr 5e-5 \
    --lr-encoder 7e-5 \
    --early-stopping \
    --early-stopping-patience 20 \
    --early-stopping-min-delta 0.0005 \
    --tensorboard \
    --wandb \
    --project "high-accuracy-training"
```

### 资源受限训练策略

适用于GPU内存受限环境：

```bash
python tools/train.py \
    --model nano \
    --dataset-dir datasets/my_dataset \
    --epochs 300 \
    --batch-size 2 \
    --grad-accum-steps 8 \
    --lr 2e-4 \
    --num-workers 1 \
    --early-stopping
```

## 多GPU分布式训练

对于多GPU环境，使用以下命令：

```bash
# 使用 torch.distributed.launch
python -m torch.distributed.launch \
    --nproc_per_node=2 \
    --use_env \
    tools/train.py \
    --model medium \
    --dataset-dir datasets/my_dataset \
    --batch-size 2 \
    --grad-accum-steps 8

# 或使用提供的脚本
./tools/train.sh
```

## 常见问题解决

### 内存不足 (OOM)

- 降低 `--batch-size`
- 增加 `--grad-accum-steps` 保持等效批大小
- 降低 `--num-workers`
- 选择更小的模型（nano/small）

### 训练速度慢

- 增加 `--num-workers`
- 使用更大的 `--batch-size`
- 启用 `--multi-scale=False` （牺牲精度）
- 检查数据集是否在SSD上

### 过拟合

- 启用 `--early-stopping`
- 增加 `--weight-decay`
- 降低学习率
- 使用更多数据增强

### 欠拟合

- 增加 `--epochs`
- 提高学习率
- 降低 `--weight-decay`
- 使用更大的模型

## 输出文件说明

训练完成后，`output_dir` 目录将包含：

```
output/
├── checkpoints/          # 模型检查点
├── logs/                # 训练日志
├── tensorboard/         # TensorBoard日志文件
├── plots/              # 训练指标图表
├── best_model.pth      # 最佳模型权重
└── final_model.pth     # 最终模型权重
```

## 环境变量

可以通过环境变量覆盖默认设置：

```bash
export RF_DETR_OUTPUT_DIR="/path/to/output"
export RF_DETR_NUM_WORKERS=4
export CUDA_VISIBLE_DEVICES=0,1

python tools/train.py --dataset-dir datasets/my_dataset
```
